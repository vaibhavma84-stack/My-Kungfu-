# Deck Log — the copy for a phone

This folder is what GitHub Pages serves, at
`https://vaibhavma84-stack.github.io/My-Kungfu-/`.

It is the **Deck Log**: everything except the world map, about 3.5 MB, so an
iPhone can install it from Safari and keep the whole thing offline. The map is
45.9 MB and lives in its own app, which is not published here yet. That split is
the only reason this folder exists — a 46 MB web app is past what iOS will keep
for a page added to the Home Screen.

Generated by `build-site.py` in the app's own repository. Nothing here is edited
by hand; copy `site/` over it and commit.

`sw.js` is the service worker that makes it open with no signal. Its cache name
carries a digest of `index.html`, not just `APP_BUILD` — so a page rebuilt
without a version bump still replaces the one already on the phone. Named after
the version alone, a phone that went to sea after such a rebuild would serve the
old page for ever, because the only thing that replaces it is a visit with a
link.

Pages is set to **Settings → Pages → Deploy from a branch → `main`, folder
`/docs`**. Serving from the repository root instead publishes the Android page,
which is the whole 46 MB app with the map in it.
