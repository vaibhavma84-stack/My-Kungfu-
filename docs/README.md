# Deck Log — the copy for a phone

This folder is what GitHub Pages serves. It is the **Deck Log**: everything
except the world map, about 2 MB, so an iPhone can install it and keep it
offline. The map is 45.9 MB and lives in its own app, which is not published
here yet.

Generated by `build-site.py` in the app's own repository. Nothing here is
edited by hand.

To publish it: repository **Settings → Pages → Source: Deploy from a branch →
Branch: `main`, folder `/docs`**. The app is then at
`https://vaibhavma84-stack.github.io/My-Kungfu-/`.
